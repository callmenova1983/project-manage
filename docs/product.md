# 产品范围与当前验收

首页优先提供最新项目情况、已发生/完成事项、每天/每周工作和整体任务情况。五阶段：潜在需求、前期沟通/方案报价、已立项待实施、实施中、验收后运营。责任维度独立；项目组自行控制进度，完成数作为辅助，不做延期驾驶舱。

默认收起侧栏、深色列表、展开行编辑与粘贴、项目详情、任务视图、活动历史、会议整理审核和工作区导入导出已实现。团队成员共享全部项目，跨工作区不可访问；负责人不是权限边界。

采用 20 项目、150 叶子任务的合成数据。父任务仅分组，工作范围与到期日分离。所有统计从共享数据派生。无真实客户项目、个人信息或业务纪要。

会议整理目前明确是规则辅助，AI 未连接。人工选择归属、确认每条修改，覆盖需二次确认；支持追溯原文行号和变更历史。

已执行的检查和边界见 `verification.md`。产品视觉参考的实际交付阻碍见根目录 `design-qa.md`。未进行生产部署或生产上线验收。
