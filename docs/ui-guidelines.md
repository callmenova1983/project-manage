# 项目集合页界面规范

适用范围：项目页的搜索筛选栏、视图切换、项目列表、项目卡片与阶段看板。沿用 `apps/web/src/style.css` 已有的语义颜色、间距和圆角变量，不新增一套主题。

## 内容与提示

- 默认展示项目事实、可执行操作和当前筛选状态。
- “卡片与列表共用筛选”等实现说明不占页面空间；统计口径放在相关区域的悬停提示中。
- 错误、空结果及无效链接提示必须保留，不能为减少文字而隐藏。
- 标题 16px；正文 14px、行高 1.65；负责人和统计标签 13px。卡片名称允许换行，摘要最多三行；列表名称采用下方的单行规则。

## 尺寸与留白

| 元素 | 规则 |
| --- | --- |
| 桌面搜索、筛选按钮、选择框 | 40px 高 |
| 手机控件 | 至少 44px 高；输入字号 16px |
| 同组操作间距 | `--space-2`，8px |
| 信息组、卡片内部间距 | `--space-4`，16px |
| 工具栏与内容、卡片之间 | `--space-5`，24px |
| 卡片内边距 | 桌面 24px；手机 16px |
| 卡片圆角 | `--radius-lg`，12px |

视图切换使用一个分段控件；桌面内部按钮 32px 高，手机至少 44px。普通操作按钮和该分段控件不混用外观。

## 宽度与响应式

- 依据项目内容区域的实际宽度排版，包含 AI 侧栏占用空间后的变化。
- 卡片期望最小宽度 360px，空间不足自动换列；窄屏允许单张卡片小于 360px，不能撑出页面。
- 卡片网格直接使用 `auto-fill`，不以屏幕宽度强制三列。
- 工具栏可用宽度小于 720px 时搜索独占一行，关注、筛选和排序在下一行排列。
- 状态与负责人同组，摘要单独成段，统计与摘要之间有明确分隔。
- 卡片仅显示阶段标签，不常驻阶段下拉框；阶段调整沿用已有拖拽入口和单项目编辑，不另加重复操作。
- 看板保留列内卡片与可水平滚动的列容器，滚动不能传递为整页横向溢出。

## 项目列表

- 桌面名称区域固定为两层：第一行只有项目名称，第二行显示客户与渠道。两层均为单行省略；不能将负责人、阶段等信息拼接进名称展示。
- 名称字号 16px、行高 24px；辅助信息字号 12px、行高 16px，桌面两层相隔 4px。展开、关注和拖动图标使用 24px 高度，与名称行顶边对齐，不能围绕整块两行文字居中。
- 长名称使用省略号，悬停展示完整的实际名称。桌面普通行高 60px，上下内边距各 8px；同一行的项目名、阶段与进展从同一顶边排起。只有多条工作内容或展开编辑器时才随内容增高，不为无内容的区域预留高度。
- 第一列至少 320px；列间距 16px。空间不足时在表格内部滚动，不压缩名称和进展列。
- 重命名、合并按钮在桌面悬停或键盘聚焦当前行时显示于标题行末端，不占默认名称宽度，也不改变行高；手机将其放在名称下方，保持至少 44px 的点击区域。
- 录入文字混入实际项目名称属于数据问题；保留真实名称和编辑入口，不以自动猜测或截取修改业务字段。

## 检查边界

每次相关修改只检查桌面侧栏开启、关闭及手机布局中的受影响状态；检查键盘焦点、操作标签和横向溢出。截图不能单独证明完整无障碍合规，也不能替代业务保存验证。
