# AI 语义入口与旧逻辑清理

2026-10-21。当前实现以本文件为准；旧版纪要、连续文本规则评测和截图仅作历史资料。

## 当前边界

自然语言意图、项目匹配、字段提取、上下文继承、日报/计划区分、人员归属、状态和相对日期由模型判断。程序不再根据关键词或正则先选流程，也不在模型失败后生成另一份规则结果。

- `POST /api/assistant/interpret` 是自由文本业务理解入口。它返回有类型的项目、事项、查询、归属确认或澄清计划。
- 附件用途/类别和项目归属使用 `/api/capture/classify`；图片转录、项目进展整理、任务补全、项目位置识别仍使用各自的模型适配器。它们不决定全局聊天意图，也没有本地语义兜底。
- 仅文字文件提取、CSV/TSV 单元格读取、用户明确选择的列映射、项目/人员搜索与筛选是数据读取或手工操作，保留。手工表格入口遇到自由文本会交给统一模型入口，不按标签猜字段。
- 模型返回的事项类型、状态、负责人和项目 ID 不再被规则改写。日报的汇报人、接收人和时间也由模型输出；工作区日期/时区提供给模型。工作周只读取明确的结构化字段，不从任务标题猜测。
- 项目地图显示已保存的位置或用户草稿，不按项目名称/客户名称自动猜位置。手动地址搜索、坐标输入和 AI 位置识别保留。原始地址文字保留，不因缺少坐标丢弃。

## 停用接口

以下接口返回 HTTP 410 / `AI_ENDPOINT_RETIRED`，提示更新页面并使用 AI 助手。不会调用模型、创建草稿、清理附件或修改业务数据：

- `POST /api/proposals`
- `POST /api/proposals/qwen`
- `POST /api/assistant/query`
- `POST /api/projects/:id/note-dates`

当前前端 API 合约已移除这些调用。`POST /api/proposals/:id/apply` 继续负责明确确认后的执行，已有待处理草稿和回执可以继续使用；不重解析历史原文。会话保存、导入导出和管理员配置接口继续保留，它们不是语义识别旁路。

## 移除的实现

删除独立规则建议生成器、日报正则解析、会议标题/后续事项规则切分、旧草稿上下文自动修复、连续文本标签解析、基于文件名的本地附件分类、旧关键词问答、笔记日期自动候选、按重复文字前缀猜项目分组，以及项目名称位置推断。

旧模型调用的建议校验与规则修复合并器已删除。SDK 中只服务旧建议接口的项目搜索工具链已删除，当前结构化调用至多一个模型步骤；显式配置的传输重试仍受原有额度约束。没有新增隐藏调用或自动重试。

`AI_PROVIDER=disabled` 表示未启用。历史环境值 `rules` 仅兼容为 disabled，不存在对应识别引擎。旧模型日志中的 rules 标签作为历史事实保留。

## 必须保留的程序校验

身份、权限、工作区隔离、实际 ID、字段格式、原文引文依据、版本冲突、重复记录、事务、幂等性和调用额度继续由程序校验。枚举标签转换、日历/时区计算和文件格式解析不承担自然语言业务判断。

模型失败时保留输入与原始资料，明确未写入；不假报成功。未改已有项目、任务、日志、附件、账户、密钥、额度或启用状态，也未迁移或删除历史数据库记录。

## 检查范围

使用内存数据库和模拟模型验证新入口、旧接口停用、状态归属不被重写、附件清理边界、草稿确认、幂等和表格导入。相关旧规则测试已删除或改为当前协议/历史草稿测试，历史自然语言样本保留。没有浏览器测试，没有真实云端模型调用；模拟检查不代表真实模型识别质量已验收。
