## 真实环境依赖与最小信息

| 依赖 | 最少需要提供/决定的内容 | 可以开始的下一步 |
| --- | --- | --- |
| 持续运行的托管入口 | 已有测试环境的所有权/操作人、预期 URL/区域；若没有，先决定可用预算上限和候选运行位置，再审阅具体方案 | 审阅部署配置、HTTPS 来源、私有数据卷、备份恢复/监控及回滚范围；单独授权后才部署。当前没有自动部署或改 Codespaces 可见性/计费 |
| 真机与 0 KB 现场 | 优先设备型号、OS/浏览器版本、实际入口及失败时间；可提供脱敏 HTTP 状态/字节数/重定向记录 | 登录→录入→刷新恢复→保存→列表每设备至少三轮，覆盖软件键盘、后台恢复和真实断网；归因上游响应与应用错误 |
| 五人和七天试用 | 五名获准参与者或由用户代执行、试用时间窗口、数据范围及证据存放位置；先用合成或获准脱敏内容 | 建立人的录入/找事实基线，记录成功/失败及耗时；连续七天观察后由用户验收，不把短时自动回归当七天试用 |
| 后续增强/架构选择 | 当前三项已实现；若未来需要跨设备偏好同步、更多编辑器类型或更低的大列表挂载成本，再明确范围与交互要求 | 不重启已收口的微优化循环。分页/虚拟化等方案需评估焦点、展开编辑器和浏览器查找，不能削减数据或改变权限来凑跑分 |
| 可选真实模型 | 是否需要现在评测；需要时指定区域、获准模型/账号、明确额度/有效期和允许外发的样本范围，凭据只通过服务端安全配置渠道提供 | 先检查脱敏连接与限额，再在单独授权下做有限真实调用和人工审阅对照；未授权前保持关闭，聊天及公开仓库不接收密钥 |
| 可选内置语音转写 | 该能力当前**未实现**；需先决定是否需要、录音/转写供应商、音频保存/外发范围及费用授权 | 仅在另立范围后评估实现。操作系统听写输入不算本应用已接入转写服务，不自动接入任何外部音频服务 |

要开始核心产品的下一步验收，首先只需确定 **测试托管入口/操作人、优先设备、五人七天试用窗口与数据范围**。真实 AI 密钥和语音供应商不是这一步的前置条件。若目前不具备试用环境，可先选择一项明确的待开发代码需求；无需把整季其余项目一并授权。
