# 个人偏好、简洁审阅与编辑草稿

## 可复用列映射

读取 Excel/CSV/TSV 后，可给当前列映射命名并保存；再次打开文件时选择模板并明确点击「应用映射」，随后仍可逐列修改、更新或删除。最多 20 个模板，按浏览器、运行模式、工作区及用户 ID 隔离。存储失败明确提示，不中断手动映射；这不是跨设备云端偏好同步。

模板只保存名称、列名、字段和是否存在标题行，不保存原始数据行、项目资料或导入确认。带标题的文件按唯一列名匹配，支持列重排；缺失、空白、重复列名留作忽略，不猜测。无标题模板仅在列数相同时按位置复用，并需检查映射。新文件仍走候选审阅，保存模板不会创建项目或任务。

## 项目分组和待决定视图

审阅打开时按来源项目分组；分组保持稳定，编辑名称不会让输入框重新挂载而丢失焦点。可切换查看全部条目或待决定条目，包括未归属项目、缺少必填值、未确认多项目匹配、未确认重复项以及需要核查的原文警告。一般规则说明不会把所有条目都列作待决定。

筛选只改变显示，创建仍包含全部已选条目，底部数量取自完整候选集合。确认后条目从待决定视图移除时，键盘焦点回到视图选择器。全部条目保留逐行原文与上下文；多匹配确认、重复确认、既有项目版本校验、事务创建与受保护撤销继续执行。缺少客户、负责人、日期或阶段仍可先保存；不通过模板猜测事实。

## 项目关注

列表星标和详情星标可关注/取消关注项目，状态通过 `aria-pressed` 提供给键盘与读屏。列表「关注」是可切换的个人筛选，可与搜索、阶段、负责人、职责和分类组合；清除筛选可回到全部项目。工作区总量不因关注改变，项目资料、审计和权限不写入关注状态，全员仍可查看编辑未关注项目。

仅保存有界的项目 ID 集合，按运行模式、工作区和账号隔离于当前浏览器。刷新保留星标，切换账号同步清理内存后读取该账号偏好；显式退出不删除个人偏好。存储失败时保持原选择并显示提示；暂无跨设备同步或多标签页即时偏好同步。

两项单元测试覆盖边界、去重、损坏数据和存储失败。14 个相关浏览器用例通过，包含原有十种偏好/历史导航检查和四个关注场景：中英文深浅主题、桌面/390px、组合过滤/空态/键盘/刷新、未关注项目编辑入口、账号隔离及存储失败。关注操作前后合成业务快照完全一致；axe 和无横向溢出通过。截图已打开检查：[深色桌面](screenshots/personal-following-desktop.png)、[中文浅色窄屏](screenshots/personal-following-mobile.png)。

## 项目、任务/子任务与行内笔记草稿

这些编辑器会把未提交输入保存在当前标签页 sessionStorage，按模式、工作区、用户、项目、实体及子任务父项隔离。输入暂存去抖 200ms，刷新/离开/后台时同步尝试写入；草稿最长保留 24 小时，过期在下次读取时清理。浏览器关闭标签页、进程回收或存储策略可能清除内容，不承诺跨设备或关闭浏览器后恢复。

刷新后重新打开同一编辑器，会先看到恢复提示，编辑字段和保存被禁用。点击「核验并恢复草稿」重新读取工作区并比较实体版本；新任务/子任务核对所属项目或父项版本。仅匹配版本可恢复；网络错误可重试，版本变化或实体不可用时旧草稿保持只读供查看，明确丢弃后加载最新内容，不把旧字段套到新版本。恢复本身不写工作区，仍须通过现有表单/服务端校验并手动保存。笔记日期建议的确认与覆盖同意不会随草稿恢复。

有过保存尝试的新建草稿，在刷新后保持只读并提示核对工作区，避免服务器已创建但响应丢失时直接重提。即使是 4xx，也可能来自中间代理且返回内容不可读，因此不凭 HTTP 状态清除保存尝试标记。原编辑器内不刷新重试仍沿用既有请求幂等机制。本批未新增自动合并或跨刷新自动重放 API。

保存成功、明确取消未提交更改或点击「丢弃草稿」会清除对应草稿；直接关闭尚未选择恢复的编辑器保留旧草稿。路由离开提示说明草稿仍留在标签页。显式退出清除当前标签页该账号所有编辑草稿，过期会话保留给原账号；另一个账号读取不同键，视图也按账号身份重建，恢复请求完成后还要确认组件与账号仍有效。存储读写/删除失败明确提示，不把失败当成可靠暂存；退出已成功但本地清理失败时，登录页提示手动清除站点数据，不显示草稿内容。

六项存储单元测试覆盖不完整值/空白/别名、模式与账号/项目/父项隔离、24h 过期、账号清理、损坏/过大/未来版本、保存尝试状态及存储失败。新增九个浏览器场景通过：双语桌面/390px 恢复与校验、任务及子任务隔离/取消、笔记路由返回和保存后再次编辑、过期版本只读、过期会话账号切换/退出、网络核验失败重试、手动刷新抢先完成时旧核验响应不能批准恢复，以及真实临时 SQLite 已创建后分别丢弃响应或返回不可读 400 时的防重复。不可读 400 用例先复现缺陷，再去除错误的 4xx 状态推断后通过。源代码没有修改认证、CSRF、服务端版本或幂等规则。
