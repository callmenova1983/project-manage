# 个人录入偏好与简洁审阅

## 可复用列映射

读取 Excel/CSV/TSV 后，可给当前列映射命名并保存；再次打开文件时选择模板并明确点击「应用映射」，随后仍可逐列修改、更新或删除。最多 20 个模板，按浏览器、运行模式、工作区及用户 ID 隔离。存储失败明确提示，不中断手动映射；这不是跨设备云端偏好同步。

模板只保存名称、列名、字段和是否存在标题行，不保存原始数据行、项目资料或导入确认。带标题的文件按唯一列名匹配，支持列重排；缺失、空白、重复列名留作忽略，不猜测。无标题模板仅在列数相同时按位置复用，并需检查映射。新文件仍走候选审阅，保存模板不会创建项目或任务。

## 项目分组和待决定视图

审阅打开时按来源项目分组；分组保持稳定，编辑名称不会让输入框重新挂载而丢失焦点。可切换查看全部条目或待决定条目，包括未归属项目、缺少必填值、未确认多项目匹配、未确认重复项以及需要核查的原文警告。一般规则说明不会把所有条目都列作待决定。

筛选只改变显示，创建仍包含全部已选条目，底部数量取自完整候选集合。确认后条目从待决定视图移除时，键盘焦点回到视图选择器。全部条目保留逐行原文与上下文；多匹配确认、重复确认、既有项目版本校验、事务创建与受保护撤销继续执行。缺少客户、负责人、日期或阶段仍可先保存；不通过模板猜测事实。

## 验证边界

本批使用合成文件、演示数据和独立 E2E 数据库。三项单元测试覆盖重排列、重复/空标题、无标题列数、存储失败、账号/工作区/模式隔离、分组来源和确认逻辑；相关四文件共 88 个测试通过。原有 16 个录入/上下文/恢复浏览器用例通过；新增四个用例覆盖 Excel→重排 CSV 复用修改删除、中英文桌面/390px、同浏览器账号切换，以及待决定视图中的歧义、来源、缺字段保存和完整撤销。最终结果与后续功能见 [验证记录](verification.md)。
