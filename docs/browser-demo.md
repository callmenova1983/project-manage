# 一键浏览器演示

正常构建部署后，直接打开同一站点的 **`/demo/`**，无需账号或密码。正式登录页也有 “Try demo · no sign-in required” 入口。路由会进入 `/demo/projects`；项目、任务、活动、会议纪要及设置继续使用 `/demo/` 前缀。

## 数据与功能边界

- 首次打开由同一个合成种子生成 20 个虚构项目和 150 个叶子任务；示例人物和工作内容均为虚构。
- 可编辑项目和任务、更新状态、创建子任务、保存笔记、导入／导出 JSON。保存后在同一浏览器刷新仍保留。
- 数据存于该站点的 `localStorage`，键为 `project-manage-demo-v1`。换浏览器、无痕窗口、清除站点数据或切换站点地址不会共享这些修改；可使用设置页导出备份。
- 演示适配器不请求 `/api/`、不申请后端会话、不读写服务器数据库。已有正式会话也不会被演示退出或重置。
- 正式 `/projects` 仍要求账号登录，`/api/` 仍执行原有认证、CSRF 和来源检查。匿名演示不授予真实账号权限。
- 会议纪要仅用本地名称/别名规则生成可审阅建议，清楚标识 “AI is not connected”。不会调用 Qwen；应用任何建议仍须逐项确认。
- 演示仅适合合成内容和拍摄展示，不是多人协作服务。请勿将真实业务纪要、个人资料或凭证粘贴到演示或公开提交中。

## 部署

使用**正常构建**，不设置 `VITE_DEMO_MODE=1`：

```bash
npm ci
npm run build
npm start
```

按原服务的生产环境配置、数据库路径与启停方式重启。`/demo/` 使用同一份前端构建；现有 Fastify 静态回退支持直接访问和刷新深层路由。纯静态托管也需将未知非资源路径回退至 `index.html`。

`VITE_DEMO_MODE=1` 仍可用于独立、全站本地的静态演示构建。**同站保留正式工作区时不要设置它**，否则根路径界面也会选择本地适配器。

## 手机拍摄建议

1. 打开 `/demo/`，直接展示最新进展、本周具体任务与整体统计。
2. 展开 Atlas 项目，编辑 Latest reported update 并保存；刷新确认保留。
3. 新增任务、勾选 Today、保存并将状态改为 Done。
4. 从左上角菜单打开 All tasks / Meeting notes。纪要使用虚构的 `Atlas: review the demo recording`，检查来源和候选项目后再确认。
5. 需要全新素材时使用新的无痕窗口；不要为拍摄清空正式工作区数据库。

浏览器测试覆盖 1536、390、375 像素视口、保存及刷新、取消、重复点击、任务状态、详情返回、会议规则建议、无后端请求、无新会话及正式 API 匿名访问被拒绝。
