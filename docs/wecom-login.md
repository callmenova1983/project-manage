# 企业微信免登

PM 支持企业微信自建应用网页授权登录。通讯录同步、通知和免登分别配置；同步通讯录不会自动启用免登。

## 配置步骤

1. 部署包含 `022_wecom_login.sql` 的版本。启动时执行迁移；上线前备份数据库及旁边的 `.credentials-key` 文件。
2. 确认服务器 `APP_ORIGIN` 是员工能访问的正式 HTTPS 地址。
3. 管理员进入「系统管理 → 企微免登」（`/admin?tab=wecom-login`），填写企业 CorpID、PM 自建应用 AgentID 和 Secret，保存并启用。
4. 点击「检查已保存的应用凭据」。此检查验证服务端凭据与应用 AgentID，不代表客户端授权已经通过。
5. 将页面生成的工作台入口填入企微应用主页，配置网页授权可信域名、应用可见范围、服务器可信 IP。按企微后台要求完成域名校验。
6. 完成通讯录同步。在「团队通讯录」把员工绑定到已激活的 PM 账号。绑定后默认视为已关联，免登和通知均无需额外确认关联。通知是否可发送仍取决于通知应用配置、企业一致性、成员有效状态和接收偏好。
7. 分别从手机企微、桌面企微工作台打开 PM，验证登录及项目权限，再验证任务通知链接。

## 首次访问与权限

默认仅允许已关联、已激活且未停用的账号登录。同步记录必须同时匹配 CorpID 和 UserID；历史记录缺少企业标识时需重新同步。

开启「首次访问自动开通普通成员」后，已同步的有效成员可首次登录时创建普通成员账号。系统不凭姓名自动合并；存在同邮箱账号时要求管理员先关联，防止重复账号或错误合并。没有邮箱的员工使用内部占位地址。自动创建的账号没有可用的初始密码，需要密码登录时由管理员通过现有激活/重置流程设置。

免登复用现有角色及项目权限，不授予管理员权限，不自动加入项目。已有账号未激活、禁用或成员停用均无法免登。企微登录时实时查询成员状态；已有企微会话会在本地通讯录停用或解绑后失效。远端离职状态的持续传播仍依赖通讯录同步，现有会话最长有效期为 12 小时。

## 登录行为

- 工作台入口：`/api/auth/wecom/start?workspace=<工作区ID>`，可附加经 URL 编码的 `returnTo` 站内地址。
- 回调：`/api/auth/wecom/callback`。只接受带浏览器关联 Cookie 的一次性 state，有效期 5 分钟。
- 从普通任务页面打开时，企微浏览器会在未登录且仅一个工作区启用免登时自动跳转。多个工作区启用时必须使用对应工作台入口，不猜测用户所属企业。
- 普通浏览器保留账号密码入口；本期不提供扫码登录。
- 登录失败显示中文原因并保留密码入口。企微浏览器可重试，失败页不会立即再次自动跳转。
- 主动退出后当前标签页不自动登录；再次通过工作台入口或手动免登入口可以登录。
- 管理员更换配置会使尚未完成的旧授权请求失效。关闭免登禁止新授权；已有有效 PM 会话保留至退出、禁用、成员解绑/停用或到期。

应用 Secret 使用现有工作区密钥进行 AES-256-GCM 加密，与其他企微凭据独立保存。页面及响应只显示是否已保存。管理员可以查看最近一次免登结果，不记录授权 code、access_token 或 Secret。

## 验证

- `npx vitest run tests/integration/wecom-login.test.ts`
- `npm run build`
- `npx playwright test --config playwright.wecom.config.ts`

浏览器测试使用独立内存数据库和模拟企微响应，不访问实际通讯录或修改生产数据。真实可信域名、应用可见范围及企微客户端行为必须在正式环境联调验收。
