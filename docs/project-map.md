# 项目地图

正式工作区入口为 `/project-map`，浏览器演示入口为 `/demo/project-map`。顶部“项目地图”进入地图，项目详情中的“在项目地图中查看”会定位到当前项目。演示数据只保存在当前浏览器，不连接共享后台或真实 AI。

## 位置识别与编辑

- 当前目录包含 **74 个城市、11 个区县**。项目名称、简称、描述、客户和别名中的地名优先匹配已收录区县，否则回退到所属城市；缺少可靠线索时保持未定位，多处匹配时由用户选择。
- 城市、区县均使用目录参考点，界面明确显示“城市中心”或“区县中心”。已确认的旧城市位置不会自动升级或改变。数据来源和目录范围见 [项目定位的数据与精度](project-location-data.md)。
- 输入完整的 `121.8, 29.9`（经度在前），或 `经度121.8 纬度29.9`，可保存 WGS84 坐标点。地图点选保留点选坐标，不吸附到城市中心；精度取决于用户输入或点选位置。点位不猜测所属城市，也不代表已识别到项目建筑。
- AI 分析使用已配置模型，仅返回目录中的城市或区县 ID，并附项目原文依据；服务端校验后生成目录坐标。模型不能生成坐标或自动确认。未配置模型时仍可规则识别、文字输入和地图点选。
- 新建或编辑项目时，在“地址 / 城市 / 区县”填写位置；也可从“项目详情 → 修改项目位置”进入。保存会确认所选位置，未知或歧义文本不会覆盖原位置；只有“清除定位”明确移除已存位置。
- 地图中的文字定位、AI 候选和点选先形成待确认位置，点击确认后保存。项目切换保留各自草稿；离开页面会提示未保存修改。保存沿用项目版本检查，旧编辑器不会因未提交位置字段而清掉已有位置。

## 地图与巡航

### 英文展示

切换 EN 后，项目标题、简称、客户、最新进展、定位依据和自定义阶段使用独立英文展示层；原始项目字段不写回。城市/区县使用英文地名，负责人使用拼音，总部标签、加载错误、无障碍标签与顶部 AI 入口随语言切换。搜索支持原名、拼音回退和已翻译名称。

已启用 AI 时自动调用 `/api/project-map/translate`，优先翻译当前项目，然后分批翻译其余项目内容。使用既有鉴权、CSRF、幂等键、调用额度和模型日志；不创建提案或修改项目。客户端按账号/工作区和原文缓存，服务端复用同一用户同一原文批次的成功结果，内容变化自动失效。请求间隔至少 12.5 秒，失败停止自动重试并提供 Retry translation。

翻译等待/不可用时，名称以术语英文和拼音回退，进展显示明确的英文等待/不可用提示，不把中文或拼音句子当成英文译文。浏览器本地 demo 不连接真实模型，因此只验证英文地名和名称回退；真实 AI 翻译需要后端已配置模型。用户主动输入的地址草稿仍保留输入原文，以免丢失编辑内容。

2026-10-17 英文增量：35 项相关测试、完整构建通过。测试覆盖完整地名目录、英文结果校验、缓存隔离、原文保留、鉴权、重复调用、失败停止重试和地图语言切换不移动镜头。真实模型译文质量尚未验收。当前内置浏览器停留于连接失败页，浏览器安全策略阻止访问该页；虽然本地 HTTP 返回 200，本轮未取得实际英文页面截图。

### 地图与动效

地图普通入口先显示大地球远景，影像就绪后停留约 **180 ms**，用约 **1.5 秒** 平滑推进到宁波总部的区域近景。该过程每次进入页面只播放一次；拖动、缩放、键盘移动、选项目或主动总览可接管镜头，异步数据更新与窗口缩放不会重播或改变落点。带 `?project=` 的有效链接仍直接聚焦该项目。“项目总览”按真实点位和城市线路端点适配取景，给标题、摘要卡、底栏预留空间；“返回全球”保留地球远景。

入场推进落定后播放约 **1.05 秒** 的总部扇区扫描与线路渐显，项目切换重放一次扫描；手动打断推进不会延迟触发落地扫描。减少动态效果时直接落定并显示连线。现有基础线路仍为一个静态绘制批次，扫描只在活动期间增加一个复用 Mesh；不引入动效依赖或新影像。总部点约 14 CSS px、选中光圈最大约 44 CSS px，缩放时保持屏幕尺寸。

首屏显示项目总数、覆盖城市、实施中和验收后运营数量（全工作区口径，覆盖城市含候选且不推测自由点城市）。右卡默认显示负责人、客户、最新进展与位置精度/确认状态；“编辑位置”或右上“位置管理”展开识别、输入和确认工具。

地图按实际位置聚合项目。切换不同位置时用约 **700 ms** 镜头过渡，项目卡片以约 **560 ms** 的轻量转牌衔接；相同位置的项目切换不移动相机，仍显示转牌和选中点脉冲。城市和区县显示的坐标保持原值，不为避让标签而偏移。

巡航默认关闭，用户通过右上角“项目巡航”启用。默认 **5 秒** 停留，底部速度菜单可切换为 **2 秒** 快速巡航，运行中切换速度会重置唯一计时器。优先切换到不同城市的项目。区县按父城市归组；未标明城市的精确坐标只按自身坐标归组，不猜测所属城市。每轮包含筛选结果中的所有已定位项目且各一次，循环首尾也尽量跨城；只有单城或某城市项目数量明显占优时，才保留不可避免的同城相邻。底部轨道和前后箭头同样采用跨城组合顺序，未定位项目放在末尾、不参与自动巡航。

开启时基于当前项目固定巡航顺序，巡航中不会反复重排。至少需要两个可定位项目；待确认建议也可参与巡航。手动选择项目、拖动或缩放地图、修改筛选、编辑或保存位置会暂停巡航；页面隐藏、位置集合变化或存在未保存草稿时也会暂停。再次启用需由用户操作。

地图默认常驻“**宁波总部 → 各项目城市**”青灰细线，按筛选结果的父城市去重，合并为一个静态绘制批次；多个区县或项目不会重复增加同一城市基础线。总部使用宁波城市参考点，非总部建筑地址。另用一条“**宁波总部 → 当前项目实际点位**”高亮线和单个流光，跟随当前项目阶段色；同位置切换也会更新颜色和脉冲。宁波本城不画零长度基础线；无父城市的自由坐标点仅保留选中时的精确连线。减少动态效果偏好会抑制镜头动画、脉冲和转牌。

## 本地验证

运行环境使用 Node.js 24。构建命令：

```sh
npm run build
```

聚焦回归覆盖目录与坐标解析、位置保存和版本冲突、草稿恢复、球面坐标/连线以及渲染状态同步：

```sh
npx vitest run tests/unit/project-location.test.ts tests/integration/project-location.test.ts tests/unit/editor-drafts.test.ts tests/unit/earth-scene.test.ts tests/unit/earth-scene-state.test.ts tests/unit/project-map-tour.test.ts
```

静态检查与单元/集成测试不代表生产部署、真实 AI 调用或真实用户数据流程已验收。位置编辑的浏览器回归位于 `tests/e2e/project-location-editor.spec.ts`，视觉效果仍需在支持 WebGL 的浏览器中检查。
