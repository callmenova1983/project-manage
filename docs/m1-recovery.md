## 存储约定

- 仅使用当前源的 `sessionStorage`，键包含适配模式、工作区 ID、账号 ID；不写入共享后端或演示 localStorage 数据，不存密码、cookie、激活令牌或 API 密钥。源材料本身留在当前浏览器，和已提交的共享项目严格区分。
- 最后暂存后最多 24 小时可恢复；到期在读取时清理，并非关闭页面后仍运行定时删除。关闭标签页、浏览器回收、拒绝存储等可能使草稿不可恢复；不会宣称离线永久备份或跨设备同步。
- 只保留已选工作表及其已解析单元格；其他表需重新选文件。不保存 XLSX 二进制。草稿最多 2,000,000 个序列化字符，不静默截断；超限、配额或策略错误明确提示保留页面并复制原文。旧暂存可能仍存在，但更新后的编辑不保证恢复。
- 200ms 合并暂存，页面隐藏、卸载或组件离开时同步尝试最后一次暂存。格式／版本损坏的记录不自动覆盖，提供显式丢弃。
- 恢复不代表保存成功。如果此前请求结果不确定，应先核对 Recent intakes；内存中的 HTTP 幂等键支持同页面重试，但本批未新增跨刷新持久化幂等收据。重复候选仍走既有重复确认和版本保护。

## 验证记录

本批的可重复自动化位于 `tests/unit/{intake-drafts,session-recovery,http-recovery}.test.ts` 与 `tests/e2e/recovery.spec.ts`。覆盖原文／空白／未完成字段、目标版本、确认清除、模式与账号隔离、24h 过期、损坏／未来版本、容量失败、服务故障重试、迟到响应、文本和 XLSX 恢复、取消、路由返回、正式保存失败及退出清理。

本地结果：lint、typecheck、format、diff 检查和 build 通过；191 个单元／API 测试通过；完整 60 项 Chromium E2E 通过（5.7 分钟），随后补充跨账号恢复用例并收紧预期错误过滤，最终恢复专项 8/8 通过（59.8 秒）。最终套件共 61 项，由精确提交 CI 再完整执行；该 CI 结果以交接链接为准。最后编译产物浏览器 smoke 验证认证、静态路由、隔离演示持久化及进程重启，意外控制台错误为 0；本地 Codespaces 代理回放也通过、意外错误为 0，未访问真实部署。CI 新增 format 检查和编译产物浏览器 smoke，浏览器安装后再运行；smoke 支持系统 Chromium 或 Playwright 自带浏览器。
