# 实施路线

所有条目当前均为待开发。

## 0. 工程基础

- 确定依赖版本、包管理器与部署方式
- 搭建 Web/API 工作区，增加环境变量示例
- 配置类型检查、测试、格式检查与 CI

## 1. 核心项目管理

- 公司成员全项目共享编辑及公司边界隔离
- 项目/任务 API、卡片看板与双击原地编辑
- 生命周期五阶段与责任维度分离
- 服务端校验、实时同步、并发冲突提示、版本审计与恢复

## 2. 自由配置

- 自定义字段及数据迁移约束
- 自定义状态与流转
- 列表/看板和保存视图

## 3. AI 建议闭环

- 服务端模型适配与成本限制
- 文字/表格及多项目材料拆分，提取进展、待办、负责人、日期与部门
- 项目别名及上下文匹配，不确定项针对性确认
- 就地展示建议，预览、编辑、确认、执行和来源追溯
- 明确配置后实现每日项目审视、确定性统计和证据支持的风险发现
- 非 AI 模式与错误恢复

## 4. 扩展

根据真实反馈选择日历、时间线、模板、自动化或外部集成，避免首版过度扩张。
