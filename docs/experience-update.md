# 第一批：双语、双主题与项目跟踪

本批围绕三个问题：所有项目现在怎样、本周实际变了什么、接下来做什么。保留紧凑列表和默认收起的侧栏，不加入甘特、日历、延期驾驶舱或角色权限孤岛。

## 已实现

- 顶部和登录页提供 EN / 中文切换；语言保存在 `project-manage-locale`，首次根据浏览器语言选择。日期和数字使用对应的 Intl 格式，工作日/工作周仍明确按 UTC；项目名、人员、任务正文和纪要原文不自动翻译。
- 深色 / 浅色切换，首次跟随系统，显式选择保存在 `project-manage-theme`。语言和主题独立。浅色有自己的背景层级、文字、边框、强调和状态色；全界面使用语义 token，保留可见焦点、悬停和禁用态。
- 五阶段概览用图标、项目数量和比较条表达全工作区分布；点击阶段可筛选，再点取消。条长比较项目数量，**不表示阶段完成百分比**。
- 今日/本周任务分布及逐项目小条均由任务状态计算，图标与可访问状态名补充颜色。父任务不重复计数，没有安排的项目不重复显示整组零值。
- “本周变化与近期事项”按需展开：从真实保存活动构建七天小柱图、最近变更时间轴与完成动作统计；点击具体变化可定位活动详情。排除初始化示例事件、未来时间、重复记录与恢复/导入产生的假完成；最多基于最近 500 条可用历史，界面明示此边界。
- 近期事项显示明确安排在今日/本周的未完成叶子任务，优先今日。截止日期只显示原有值，不改变工作范围，也不推测工作日期。
- 任务页增加全部工作 / 未完成 / 已完成关注；范围、状态、项目、搜索和关注写入 URL，返回/刷新可恢复。新建任务所属项目独立于当前筛选，保存后仍保留筛选。
- 本地演示历史恢复有独立来源标记，避免把恢复旧版本错误统计为新完成动作。

“完成动作”是保存的状态变更次数，不是当前已完成任务总数；同一任务重新打开后再次完成可以形成新的动作，导入与历史恢复不计入。

## 主题和本地化结构

- `locales/index.ts`：响应式语言选择、插值、日期/数字格式；`zh-*.ts`：分域中文词条；`locales/en.ts`：响应式阶段/任务状态标签。
- `composables/theme.ts`：系统主题与显式偏好；`style.css`：表面、文字、边框、强调、状态、阶段 token 及交互规范。
- `TaskDistribution` / `ProjectStages`：数据驱动图形；`WeeklyChanges` + `activity-summary`：保存历史；`NextWork`：明确安排的后续任务。

常见固定错误已本地化；未知服务器诊断与原始变更 JSON 保留原文，不假造翻译或改变用户内容。工作时区暂未提供单独选择。

## 验收与部署

本批测试包含双语 × 双主题 × 1536/375px 的八组界面、WCAG 2/2.1 A/AA 自动扫描、偏好独立与刷新持久、真实保存变更到历史锚点、任务关注和浏览器返回；原有 375/390px 编辑/取消/刷新/纪要审阅回归继续执行。具体执行结果见 `verification.md` 和当前提交的 CI。

仍使用正常 `npm ci`、`npm run build` 和现有 API 启停流程，不设置 `VITE_DEMO_MODE=1`。同站 `/demo/` 继续完全使用本地适配器，正式 `/projects` 和 API 保持认证/CSRF/来源校验；既有 Codespaces Origin 兼容配置继续有效。无需数据库迁移或重建种子。公网部署由部署负责人验证，不改变真实账号或启用模型。

## 下一批，尚未实现

1. **轻量录入优先。** 一段话、文本拖入、CSV/XLSX → 客户/项目/阶段/负责人/日期/待办候选 → 别名匹配和去重 → 不确定项确认 → 变更预览与提交。保留表格行/原文来源，事务化应用、可审计恢复、不静默覆盖历史。当前仅有既有 TSV 任务粘贴和纪要规则审阅，不能宣称已有完整 Excel 项目识别。
2. **语音入口。** 先兼容系统听写的文本框；只有明确浏览器支持、识别数据去向和用户主动开始/停止时才接入转文字。不自动上传音频，不把当前 Qwen 文本模型声称为 ASR。外部 ASR 需独立配置和授权，失败时保留文本输入。
3. **管理基础与用户管理。** 当前没有管理员角色或用户管理 HTTP API。先建立独立管理授权、用户启停、会话撤销和管理审计；首位真实管理员须由经授权的部署操作明确指定，不把所有项目编辑者或 demo 用户自动升级。无默认真实密码；没有邮件服务时不宣称邀请已发送。
4. **阶段/分类配置。** 当前阶段和职责是固定枚举。后续用稳定 ID、双语标签、顺序与归档状态建立注册表，保护现有引用和历史；业务分类与职责 focus 分开，导入需要版本兼容与预览，不能硬删除已引用阶段。
5. **模型配置与调用日志。** 凭证仅为服务端预注册 secret 引用和遮罩状态，不回传 key、不存前端/浏览器。保存配置不自动调用模型。记录真实 provider/model、时间、状态、耗时、可用 token usage 和错误码；未知费用显示未知，旧记录缺失字段不补造。现有 `ai_requests.response` 含原始纪要，不能直接当后台日志返回。实例级配置不得由普通工作区成员修改。

Demo 后台可用明确标记的合成状态与模拟记录，不触发管理 API、不授予服务端权限、不混入真实调用统计。真实管理员范围、用户激活凭证的私密交付渠道、模型 secret 引用/区域/预算仍需明确。以上均不阻塞本批体验交付。
