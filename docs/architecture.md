# 实现架构

## 当前实现

Vue 3 / Pinia / Vue Router → `WorkspaceApi` HTTP 适配器 → Fastify → SQLite 仓储。共享 TypeScript/Zod 领域模型统一输入校验、项目生命周期、任务关系、工作范围和统计。没有浏览器直连数据库，也没有把 localStorage 当作默认服务端。

原草稿建议 MongoDB；此次选择 Node 24 内置 SQLite，避免额外数据库服务即可运行完整前后端。此选择面向单实例、团队百项目量级的初始部署，尚未做容量验收。仓储集中在 `apps/api/src/database.ts`，可迁移到其他数据库；不要将同步 SQLite 查询直接扩展成大量阻塞运算。

## 数据与写入

表：workspaces、users、sessions、projects、tasks、activities、proposals、idempotency、migrations。实体使用工作区复合键，任务外键指向同工作区项目。父任务关系及最大 20 层的无环层级在共享领域校验中验证。

所有修改经事务提交。项目/任务使用预期版本，导入使用工作区 revision；冲突返回 409 及当前值。会话用户决定 workspace，不接受客户端指定访问范围。一次重复请求由用户+UUID 幂等键识别，事务缓存结果，7 天内重放不会重复建任务。前端在不确定的网络失败后复用同一请求 ID。

状态更新、批量粘贴、项目编辑、导入与恢复会写审计。审计保存操作者、时间、来源、前后值。普通修改可恢复到之前值，并生成新的审计版本；不能通过恢复覆盖他人新版本。导入为明确确认的整体替换，保持审计历史；恢复整次导入需要之前的数据备份。

## 协作与身份

工作区内所有已登录用户平等读写全部项目；项目负责人只表示推进责任。通过 CLI 建立账号，随机盐+scrypt 保存密码；会话 token 256 bit，仅存哈希，12 小时到期，退出即撤销。生产模式启用 Secure Cookie；SameSite=Strict、HttpOnly、CSRF token、来源校验、请求体限制、输入校验、限流、安全响应头共同约束访问。

客户端每 20 秒或手动刷新共享快照。正在编辑的草稿保留自己的基础版本；保存时检查最新版本，不静默覆盖。此实现是轮询同步，不是 WebSocket 实时协作。没有对外通知，也没有角色权限孤岛。

## 会议建议

默认采用确定性文本规则；可选 Qwen 服务端适配位于 `apps/api/src/ai`，默认关闭且尚未进行真实调用。原文及 sourceVersion=1 保存在 proposals；规则候选按名称/别名匹配，模型候选通过结构和原文证据校验。每条必须人工确认，覆盖最新报告额外确认并校验项目版本。整批应用是事务，已应用的 proposal 不可再次执行。来源信息随正常审计记录保存。

Qwen 仅在服务端配置官方区域端点、replacement secret 和有期限的尝试额度后开放。模型生成发生在数据库事务之外；幂等状态与每次付费尝试先持久化，成功只保存可审阅 proposal。AI 失败不会写入项目或任务，也不会自动降级后伪称模型生成。基本任务管理和浏览器 local adapter 不依赖模型。配置和边界见 [Qwen 接入说明](qwen-integration.md)。

## 前端

六个路由页面与独立的项目/任务编辑、批量粘贴、状态徽标和错误组件。Pinia 是 UI 的唯一数据快照入口；`WorkspaceApi` 定义 HTTP 与本地演示的一致接口。输入为纯文本输出，无 `v-html`。未保存离开/关闭确认、保存禁用、错误保留与可恢复冲突是编辑组件职责。

英文标签集中在 `locales/en.ts`，后续中文需补齐其余页面文案与日期/时区策略，当前不声称完成国际化。

## 尚需生产环境验证

HTTPS/反向代理配置、备份恢复演练、监控、密码恢复/MFA/SSO、生产负载、真实成员试用、浏览器兼容性与移动设备验证未覆盖。当前限流为单实例内存实现；多副本部署需共享会话与限流基础设施。生产数据不应进入源码、测试、截图或公开仓库。
