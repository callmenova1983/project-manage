# 项目数据导入与导出

「导出数据」「导入数据」统一放在工作区设置的「项目数据导入与导出」中，用于低频的数据迁移和备份。导出直接下载 JSON 数据包；导入选文件后展示新增、更新数量，一次确认后执行。

数据包包含项目字段与笔记、任务层级与排期、负责人姓名、完整活动历史、进展日志的原文与修正记录、日报批次，以及项目使用的阶段、分类、渠道定义。不导出附件文件、缩略图、附件引用、登录账号、密钥或 AI 配置。此过程不调用模型。

导入按稳定编号合并，不清空现有项目或任务；相同内容不重复写入。历史记录保留来源编号，跨工作区导入、再次导出和重复导入不会制造同一条历史的副本。导入操作本身会留痕。新分类的引入遵守管理员权限；已有分类定义及工作区时区不变。

导入时，当前工作区没有对应账号的人员保留姓名并解除账号引用，不根据同名自动绑定账号。失败整体回滚，并检查并发版本。原有 JSON 替换恢复保留在设置的折叠区域，仅用于旧版文件。

验证采用隔离数据库与本地存储：覆盖超过 500 条活动的导出、原文与记录人保留、附件排除、跨工作区往返、重复导入、更新合并、无关数据保留及失败回滚。不做浏览器测试，不操作真实工作区数据。
